# 📋 Способы просмотра вариаций товаров

## 🎯 Обзор

Вариации товаров (групповые товары) отображаются в списке товаров с визуальными индикаторами и возможностью фильтрации.

## 🔍 Способы просмотра вариаций

### 1. **Визуальная индикация в списке товаров**

В списке товаров (`/admin/[shop]/products`) групповые товары отображаются с фиолетовым badge:

- **Фиолетовый badge** с текстом `"Группа: {group_key}"` рядом с названием товара
- Показывает, что товар является частью группы
- При наведении показывает полный `group_key`

**Пример:**
```
Футболка [Группа: futbolka-basic]
```

### 2. **Ссылка на все варианты группы**

В колонке "Группа" (Type) для групповых товаров отображается:
- Название типа товара
- Ссылка **"🔗 Варианты"** под названием типа
- При клике фильтрует список по `group_key` и показывает все товары группы

**Как использовать:**
1. Найдите товар с фиолетовым badge в списке
2. В колонке "Группа" нажмите на ссылку "🔗 Варианты"
3. Список автоматически отфильтруется и покажет все товары этой группы

### 3. **Фильтрация по group_key через URL**

Можно напрямую открыть список всех вариантов группы через URL:

```
/admin/[shop]/products?group_key=futbolka-basic
```

**Как использовать:**
1. Узнайте `group_key` товара (отображается в badge)
2. Добавьте параметр `?group_key={group_key}` к URL списка товаров
3. Список покажет только товары с этим `group_key`

### 4. **Просмотр в редакторе товара**

При редактировании товара в визарде (`/admin/[shop]/products/[slug]/edit-wizard`):

- На шаге "Групповой товар" отображаются все варианты группы
- Можно добавлять новые варианты
- Можно объединять с другими товарами
- Видны все атрибуты каждого варианта

**Как использовать:**
1. Откройте любой товар группы для редактирования
2. Перейдите на шаг "Групповой товар"
3. Увидите список всех вариантов с их атрибутами, ценами, количеством

### 5. **Поиск по названию товара**

Если все варианты группы имеют одинаковое название (рекомендуется):

1. Введите название товара в поиск
2. Все варианты группы будут показаны в результатах
3. Отличаются по `slug` и атрибутам

## 📊 Визуальные индикаторы

### В списке товаров:

| Индикатор | Значение |
|-----------|----------|
| 🟣 Фиолетовый badge `"Группа: {key}"` | Товар является частью группы |
| 🔵 Синий badge `"Вариативный товар"` | Вариативный товар (старая система) |
| 🔗 Ссылка "Варианты" | Клик для просмотра всех вариантов группы |

### В колонке "Группа":

- **Обычный товар**: Только название типа
- **Групповой товар**: Название типа + ссылка "🔗 Варианты"

## 🔧 Технические детали

### Структура данных

```typescript
interface Product {
  id: string;
  name: string;
  slug: string;
  group_key?: string;  // Ключ группы для вариаций
  attribute_values?: Record<string, string>;  // Атрибуты варианта
  price: number;
  // ... другие поля
}
```

### API запросы

**Получение всех товаров группы:**
```typescript
GET /products?group_key={group_key}
```

**Фильтрация в списке:**
- Параметр `group_key` передается в `useProductsQuery`
- API возвращает только товары с указанным `group_key`

## 💡 Рекомендации

1. **Используйте одинаковые названия** для всех вариантов группы
2. **Уникальные slug** для каждого варианта (автоматически генерируются)
3. **Заполняйте атрибуты** для каждого варианта (цвет, размер и т.д.)
4. **Проверяйте группу** через ссылку "🔗 Варианты" после создания

## 🐛 Отладка

Если вариации не отображаются:

1. Проверьте, что товар имеет `group_key` в базе данных
2. Убедитесь, что API возвращает `group_key` в ответе
3. Проверьте консоль браузера на наличие ошибок
4. Убедитесь, что фильтр по `group_key` работает в API

## 📝 Примеры использования

### Пример 1: Просмотр всех вариантов футболки

1. Откройте список товаров
2. Найдите товар "Футболка" с badge "Группа: futbolka-basic"
3. Нажмите "🔗 Варианты" в колонке "Группа"
4. Увидите все варианты: "Футболка (черная, M)", "Футболка (белая, L)" и т.д.

### Пример 2: Прямой доступ к группе

1. Скопируйте `group_key` из badge (например, `futbolka-basic`)
2. Откройте URL: `/admin/[shop]/products?group_key=futbolka-basic`
3. Список покажет только товары этой группы

### Пример 3: Редактирование вариантов

1. Откройте любой товар группы для редактирования
2. Перейдите на шаг "Групповой товар"
3. Увидите все варианты с возможностью редактирования
4. Добавьте новый вариант или измените существующий
